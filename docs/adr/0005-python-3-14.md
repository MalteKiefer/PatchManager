# 5. Python 3.14 instead of 3.15

* Status: accepted
* Date: 2026-10-21

## Context

Python 3.15.0 is the newest release. Django 6.1.2, Celery 5.6, drf-spectacular and other
core dependencies declare support up to 3.14.

## Decision

Use Python 3.14 (latest patch, 3.14.8 at the time of writing). Move to 3.15 once Django
lists it as supported; Renovate will propose it.

## Consequences

We can use 3.14 features, notably `uuid.uuid7()` from the standard library for RFC 9562
primary keys.
